# sysbadge

Консольная утилита для Linux на Rust: выводит в терминал цветную плашку в индустриальном стиле с живыми данными системы.

```
▄██████▄ ██████▄▄ ██████ ▀▀▀▀▀▀   my-workstation                 ██ ▄██▄ ██
▀██████▀ ███  ███ ███   ™▀▀▀▀▀▀   LA   0.42   -  0.37  -  0.30   ██ ▀██▀ ██
UP 2D 04:12:33  17:09:51     >>>  ROOT                      >>>        (US)
```

## Что показывает

| Место на плашке      | Данные                                   | Откуда берётся                               |
|----------------------|------------------------------------------|----------------------------------------------|
| Заголовок            | имя машины (hostname)                    | `/proc/sys/kernel/hostname`                  |
| Строка под ним       | load average за 1 / 5 / 15 минут         | `/proc/loadavg`                              |
| Слева внизу          | uptime и текущее локальное время         | `/proc/uptime`, `/etc/localtime` или `$TZ`   |
| По центру внизу      | имя текущего пользователя                | реальный uid из `/proc/self/status` + `/etc/passwd` |
| Справа внизу         | текущая раскладка клавиатуры             | см. ниже                                     |

Раскладка определяется по очереди, пока не найдётся ответ:
Hyprland (`hyprctl`) → Sway (`swaymsg`) → KDE (`qdbus6`/`qdbus`) → GNOME (`gsettings`) →
`xkb-switch` → `setxkbmap -query` → `/etc/default/keyboard` → `localectl`.

> На чистом X11 без `xkb-switch` видна только первая раскладка из конфигурации,
> а не активная в данный момент. Чтобы видеть текущую, установите `xkb-switch`.
> Если раскладку определить не удалось, выводится `(??)`.

## Сборка

Нужен Rust (stable). Если его нет:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env
```

Сборка и запуск:

```bash
cd sysbadge
cargo build --release
./target/release/sysbadge
```

Установка, чтобы запускать из любого места:

```bash
cargo install --path .
# или
sudo cp target/release/sysbadge /usr/local/bin/
```

Внешних зависимостей нет — только стандартная библиотека Rust.

## Использование

```
sysbadge [-w] [-c ЦВЕТ]

  -c, --color ЦВЕТ   orange (по умолчанию), blue, red, white или #RRGGBB
  -w, --watch        обновлять каждую секунду (Ctrl+C — выход)
  -h, --help         справка
```

Примеры:

```bash
sysbadge                        # оранжевая плашка
sysbadge --color blue
sysbadge -c red -w              # красная, с обновлением раз в секунду
sysbadge --color=white
sysbadge --color '#00ff88'      # любой цвет в HEX (кавычки обязательны из-за #)
```

### Цвета

- Если терминал поддерживает truecolor (`COLORTERM=truecolor` или `24bit`), используется точный RGB.
- Иначе — ближайший цвет из 256-цветной палитры.
- `NO_COLOR=1 sysbadge` — вывод без цвета (например, для логов).

## Показ при открытии терминала

Добавьте в конец `~/.bashrc` или `~/.zshrc`:

```bash
sysbadge
```

## Требования

- Linux (данные читаются из `/proc`)
- Терминал с поддержкой UTF-8 и моноширинным шрифтом, в котором есть символы `█ ▀ ▄`
